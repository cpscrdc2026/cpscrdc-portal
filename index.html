CPSCR DC Scoring Rules (Asian Parliamentary)

This page is generated from the same scoring table the entry forms use, so the rules shown here always match what the portal calculates. Multi-judge panel: set N judges when recording a debate; each speaker gets N identical scorecards (Judge 1 … Judge N). Each category average = sum of the judges' marks ÷ N, the speaker's final score = average of the judges' totals, and all averages display to 2 decimals. Main speeches: 3 speakers per side, maximum 100 each. Reply speech: 1 speaker per side, maximum 50. Team total = Speaker 1 + Speaker 2 + Speaker 3 + Reply (maximum 350). Each criterion accepts 0 up to its own maximum. The leaderboard converts every appearance to a percentage of its role maximum, so reply speeches (out of 50) and main speeches (out of 100) are comparable.
